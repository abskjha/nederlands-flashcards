# Dutch Flashcards

A personal Dutch-learning flashcard web app.

This repository hosts a single-file HTML flashcard app for practicing Dutch vocabulary, meanings, examples, grammar notes, singular/plural forms, verb forms, and pronunciation.

## Live site

After enabling GitHub Pages, the app will be available at:

```text
https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY-NAME/
```

## How to use

1. Open the website.
2. Single click/tap the card to reveal the answer.
3. Single click/tap again to go to the next card.
4. Double click/tap to go backward.
5. Use the pronunciation buttons to hear Dutch words and examples where browser support is available.
